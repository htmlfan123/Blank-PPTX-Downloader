# Blank PPTX Downloader

A simple HTML-based tool that generates and downloads a blank PowerPoint presentation (`.pptx`) file in the browser.

## What it does

This project uses `PptxGenJS` to create a new presentation, set it to a wide slide layout, add one blank slide, and trigger a download of the resulting file as:

- `blank-presentation.pptx`

## Project structure

- `index.html` – the complete web app interface and JavaScript logic
- `LICENSE` – MIT license

## How to use

1. Open `index.html` in a browser.
2. Click the `Download Blank PPTX` button.
3. The browser downloads a blank PowerPoint presentation.

## Technologies used

- HTML
- JavaScript
- [PptxGenJS](https://gitbrent.github.io/PptxGenJS/)
